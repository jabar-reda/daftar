[جرّب دفتر الآن](https://jabar-reda.github.io/daftar/)

مفكرة ملاحظات عربية تعمل كلها في المتصفح. تكتب، تعدّل، تحذف، وتبحث — وملاحظاتك
تُحفظ على جهازك فقط. بلا حساب ولا خادم ولا إرسال أي بيانات.

## الاستخدام

| الإجراء | الطريقة |
|---|---|
| إضافة ملاحظة | اكتب في المُحرِّر أعلى الصفحة ثم اضغط **أضف** |
| إضافة أسرع | `Ctrl + Enter` (أو `Cmd + Enter` على macOS) |
| تعديل | زر ✎ بجانب الملاحظة، عدّل، ثم **حفظ** |
| إلغاء التعديل | زر **إلغاء** |
| حذف | زر ✕ ثم **حذف** في نافذة التأكيد |
| بحث | اكتب في حقل **بحث** أعلى الصفحة |

تظهر نتائج البحث أثناء الكتابة، وتُرتَّب الملاحظات الأحدث أولاً بتاريخ عربي مثل «٤ نوفمبر».
أزرار ✎ و ✕ تظهر عند مرور الفأرة على الملاحظة، أو عند لمسها على الهاتف.

يمكن التنقل كاملاً بلوحة المفاتيح، وتتحدث قارئات الشاشة عن كل تغيير، ويُحترم
تفضيل تقليل الحركة في النظام.

## التشغيل

افتح `index.html` في المتصفح مباشرة. لا تثبيت ولا خطوة بناء.

عند أول زيارة تظهر نافذة ترحيب قصيرة؛ زر «لا تُظهر هذه النافذة مجدداً» يخفيها نهائياً.

> بعض المتصفحات تمنع التخزين على `file://` فتضيع الملاحظات عند إغلاق التبويب.
> إن حدث ذلك شغّل خادماً محلياً بسيطاً:
>
> ```bash
> python -m http.server 8000
> ```
>
> ثم افتح <http://localhost:8000>.

التطبيق لا يحتاج إنترنت إطلاقاً — الخطوط محفوظة معه في `src/fonts/`.

## تطبيق أندرويد (APK)

تبويب **Actions** ← **بناء APK** ← زر **Run workflow** ← نزّل APK من **Artifacts**
وثبّته على الهاتف (سمح بالتثبيت من مصادر غير معروفة). في أول تشغيل فقط: اكتب
كلمة مرور في الحقل ثم احفظ المفتاح الناتج في أسرار المستودع.

ملاحظة: ملاحظات التطبيق منفصلة عن ملاحظات المتصفح، وحذف التطبيق يمحوها.

## أين تُحفظ الملاحظات؟

في `localStorage` تحت المفتاح `daftar_v1`، على شكل مصفوفة JSON:

```json
[
  {
    "id": "lq3k9x1a2b",
    "title": "من كتاب",
    "body": "الكتابة هي القراءة مرتين...",
    "createdAt": "2026-11-04T09:15:00.000Z"
  }
]
```

- `title` أو `body` قد يكون فارغاً، وليس الاثنان معاً.
- عند أول تشغيل تجد ملاحظتين للتجربة؛ احذفهما متى شئت.
- لمسح كل شيء: أدوات المطور ← Application ← Local Storage ← احذف `daftar_v1`
  (وعلم نافذة الترحيب `daftar_seen_v1` إن أردت عودة النافذة).

## بنية المشروع

```
daftar/
├─ index.html     الهيكل فقط: بلا أنماط مضمّنة ولا سكربتات
├─ src/
│  ├─ css/
│  │  └─ styles.css  التصميم كاملاً، والألوان في أعلى الملف
│  ├─ js/
│  │  └─ app.js      المنطق كاملاً في ملف واحد
│  ├─ fonts/         ملفات الخطوط الثمانية (Amiri وAref Ruqaa)
│  └─ icons/         أيقونة الموقع (SVG وICO)
├─ apk/           أدوات بناء APK في GitHub Actions
├─ README.md      هذا الملف
├─ CONTRIBUTING.md كيف تساهم
├─ AGENTS.md      قواعد العمل على المشروع للوكلاء والمحررين
├─ .github/
│  ├─ workflows/apk.yml  بناء APK يدوي
│  └─ SECURITY.md  سياسة الأمان
└─ LICENSE        رخصة MIT
```

## للمطوّرين

- الألوان والخطوط متغيّرات في `:root` أعلى `src/css/styles.css`؛ عدّل من هناك فقط.
- مفتاح التخزين `STORAGE_KEY` في `src/js/app.js`. غيّر الرقم (`daftar_v1` ← `daftar_v2`)
  فقط عند تغيير شكل البيانات.
- لإضافة حقل جديد للملاحظة: `load()` ثم `renderEntry()` ثم `composer`، ثم ارفع رقم الإصدار.
- لا إطار عمل ولا مكتبات ولا خطوة بناء. أبقِ الأمر كذلك.
