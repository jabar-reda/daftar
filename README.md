# دفتر — Daftar

مفكرة ملاحظات عربية بسيطة تعمل كلها في المتصفح: تكتب، تعدّل، تحذف، وتبحث — وكل شيء
يُحفظ محلياً على جهازك. لا خادم، ولا حساب، ولا إرسال لأي بيانات.

## المزايا

- **إضافة سريعة:** عنوان اختياري ونص، والزر **أضف** يحفظ فوراً.
- **تعديل وحذف:** مرّر على الملاحظة (أو المسها على الهاتف) لتظهر أزرار ✎ و ✕.
- **بحث فوري:** يبحث في العنوان والنص أثناء الكتابة، بلا حساسية لحالة الأحرف.
- **ترتيب زمني:** الأحدث أولاً، مع تاريخ عربي مثل «٤ نوفمبر».
- **واجهة عربية RTL** بخطَّي Amiri و Aref Ruqaa، وتصميم ورقي هادئ.
- **إتاحة:** تنقّل بلوحة المفاتيح، وأزرار بأسماء مقروءة لقارئ الشاشة، وإعلان التغييرات
  في منطقة `aria-live`، واحترام `prefers-reduced-motion`.

## التقنيات

- **HTML** و **CSS** و **JavaScript** بسيط — بدون بناء (no build) ولا مكتبات ولا إطار عمل.
- **جرّبها الآن:** افتح `index.html` مباشرة في المتصفح.

## التشغيل

لا توجد خطوة بناء ولا تثبيت حزم:

1. افتح `index.html` بالنقر المزدوج عليه في مستطيل الملفات.
2. أو من الطرفية: `start index.html` (ويندوز).

> **ملاحظة:** بعض المتصفحات تمنع `localStorage` على بروتوكول `file://`، فتُفقد الملاحظات
> عند إغلاق التبويب. إن حدث ذلك، شغّل المجلد على خادم محلي بسيط:
>
> ```bash
> python -m http.server 8000
> ```
>
> ثم افتح <http://localhost:8000>.

الخطوط تُحمَّل من Google Fonts، فتحتاج إنترنت في أول تحميل للصفحة. بقية التطبيق يعمل
بلا إنترنت، وإن تعذّر تحميل الخطوط ظهر الخط البديل `serif` والتصميم يبقى سليماً.

## الاستخدام

| الإجراء | الطريقة |
|---|---|
| إضافة ملاحظة | اكتب في المُحرِّر أعلى الصفحة ثم اضغط **أضف** |
| إضافة سريعة | `Ctrl + Enter` (أو `Cmd + Enter` على macOS) داخل المُحرِّر |
| تعديل | زر ✎ بجانب الملاحظة، عدّل، ثم **حفظ** |
| إلغاء التعديل | زر **إلغاء** |
| حذف | زر ✕ ثم تأكيد الحذف |
| بحث | اكتب في حقل **بحث** أعلى الصفحة |

## أين تُحفظ الملاحظات؟

في `localStorage` تحت المفتاح `daftar_v1`، على شكل مصفوفة JSON:

```json
[
  {
    "id": "lq3k9x1a2b",
    "title": "من كتاب",
    "body": "الكتابة هي القراءة مرتين...",
    "createdAt": "2026-11-04T09:15:00.000Z"
  }
]
```

- `title` قد يكون فارغاً، و`body` قد يكون فارغاً، لكن ليس الاثنان معاً.
- `createdAt` بتوقيت ISO، والعرض بتنسيق `ar-EG`.
- عند أول تشغيل تُزرع ملاحظتان تجريبيتان؛ احذفهما متى شئت.
- لمسح كل شيء: أدوات المطور ← Application ← Local Storage ← احذف `daftar_v1`.


## التطوير

- **الألوان والخطوط:** كلها متغيّرات CSS في `:root` أعلى `styles.css`، عدّل من هناك فقط.
- **مفتاح التخزين:** `STORAGE_KEY` في `app.js`. تغييره يعني البدء بقائمة فارغة، فغيّر
  الرقم (`daftar_v1` ← `daftar_v2`) فقط عند تغيير شكل البيانات.
- **إضافة حقل للملاحظة:** أضفه في `load()` للنماذج الافتراضية، وفي `renderEntry()` للعرض،
  وفي `composer` عند الإنشاء، ثم ارفع رقم إصدار المفتاح.
- **لا يوجد إطار عمل ولا حزم:** HTML و CSS و JavaScript عادية. أبقِ الأمر كذلك.
