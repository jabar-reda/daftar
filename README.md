# دفتر

**مفكرة ملاحظات عربية بسيطة تعمل في المتصفح.**

اكتب، عدّل، ابحث — وكل شيء يبقى محفوظاً على جهازك، بلا حساب ولا خادم.

</div>

---

## ما هو دفتر؟

دفتر تطبيق ويب صغير لتدوين الملاحظات والأفكار والاقتباسات. صُمّم بواجهة عربية
هادئة تشبه الورق، ويعمل بالكامل في المتصفح: لا تسجيل دخول، ولا قاعدة بيانات،
ولا اتصال بالإنترنت بعد تحميل الصفحة.

## المزايا

- **إضافة وتعديل وحذف** الملاحظات مع تأكيد قبل الحذف.
- **بحث فوري** في العناوين والمحتوى أثناء الكتابة.
- **حفظ تلقائي** في `localStorage` بعد كل تغيير.
- **تواريخ عربية** منسّقة تلقائياً (اليوم والشهر، والسنة عند اختلافها).
- **إتاحة**: تسميات `aria` واضحة، إعلانات لقارئ الشاشة، واحترام `prefers-reduced-motion`.
- **تصميم متجاوب** يعمل على الهاتف والحاسوب، مع دعم كامل لاتجاه RTL.

## التشغيل

المشروع ملفات ثابتة لا تحتاج إلى بناء أو تثبيت حزم. افتح `index.html` مباشرة
في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
# Python 3
python -m http.server 8000
```

ثم افتح <http://localhost:8000>.

> ملاحظة: يفضّل استخدام خادم محلي بدل فتح الملف مباشرة، حتى تعمل الخطوط
> والملفات الخارجية بشكل صحيح.

## أين تُحفظ الملاحظات؟

تُخزَّن الملاحظات في `localStorage` تحت المفتاح `daftar_v1`، داخل متصفحك فقط.
هذا يعني:

- مسح بيانات المتصفح يمسح الملاحظات.
- الملاحظات لا تُزامَن بين الأجهزة أو المتصفحات.
- لا يُرسَل أي شيء إلى أي خادم.
